# Contributing

Thanks for helping improve Gradegarden.

## Before you start

- Search existing issues before reporting a bug or proposing a feature.
- For a substantial change, open an issue first so the scope can be discussed.
- Keep changes focused and avoid adding dependencies unless they provide clear value.

## Making changes

1. Fork the repository and create a branch for your change.
2. Keep the site dependency-free and preserve both English and Simplified Chinese for user-facing text.
3. Check calculator behavior with representative inputs, including boundary values.
4. Check desktop and mobile layouts and preserve semantic labels and keyboard accessibility.
5. Open a pull request with a concise summary and the checks you performed.

## Reporting issues

Use the GitHub issue templates for bugs and feature requests. Do not include private student records or other sensitive personal information.
